# Portland Tide

A PWA tide chart for Portland, ME built with [Observable Framework](https://observablehq.com/framework).

## Redeploying

Tide data is generated by an R script (`docs/data/tideData.csv.R`) covering 15 days back and 365 days forward from the build date. Redeploy when the data window needs refreshing (roughly once a year).

### Steps

1. **Regenerate the data and build:**
   ```bash
   npm run clean   # clears cached tide data, forcing R script to re-run
   npm run build   # runs the R script and builds dist/
   ```

2. **Deploy to GitHub Pages:**

   Push to `main` — the GitHub Action handles deployment automatically. Or trigger it manually from the Actions tab.

   The site is served at `https://rbcavanaugh.github.io/observable-tide/`.

3. **Commit and push** to keep the repo in sync.

### R dependencies

The data loader requires these R packages:
```r
install.packages(c("lubridate", "rtide", "dplyr", "readr", "stringr", "tidyr"))
```

### Automated refresh

A GitHub Action (`.github/workflows/refresh.yml`) runs `npm run clean && npm run build` on January 1 each year and can also be triggered manually from the Actions tab. It does **not** deploy — run `npm run deploy` locally after it completes.

## Local development

```bash
npm run dev
```

Then visit <http://localhost:3000>.

## Command reference

| Command | Description |
| --- | --- |
| `npm run dev` | Start local preview server |
| `npm run build` | Build static site into `./dist` |
| `npm run clean` | Clear cached data (forces R script to re-run on next build) |
| `npm run deploy` | Deploy to Observable |
